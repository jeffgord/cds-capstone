Book graph

Each dot is a book, linked to the 10 books most similar to it. Colours are Library of Congress (LoC) main classes, which are never used to build the graph. If a model groups books the way librarians do, the colours cluster.

    Hover a book to see its neighbours (in both graphs when comparing). Click to open it in search. Click a class to highlight it. Scores are on held-out books and exploratory: there are no relevance labels yet.

    A capstone prototype for NYU Libraries, not affiliated with Project Gutenberg. Book data from gutenberg.org.
